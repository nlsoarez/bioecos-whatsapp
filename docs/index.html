02 — Segurança operacional

O que não pode depender de uma resposta probabilística.

As decisões críticas ficam no código, não no prompt. Segredos permanecem fora do Git e os dados pessoais sensíveis são cifrados.

  • Anti-duplicidadeEventos repetidos não geram respostas repetidas.
  • Pausa efetivaIntervenção humana interrompe a IA imediatamente.
  • CPF cifradoAES-256-GCM com chave exclusiva do ambiente.
  • Admin protegidoRotas administrativas exigem chave separada.
  • AuditoriaMudanças e ferramentas executadas deixam rastros.
